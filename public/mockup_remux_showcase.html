📖 Cara Menerapkan Style & Transisi Pilihan Anda

Setelah menemukan kombinasi favorit dari galeri di atas, Anda dapat menggunakannya di 2 tempat utama di MAKNA Flow:

Langkah 1 • Auto Pipeline
Form Input Auto Pipeline
Di halaman /auto-pipeline, buka baris opsi resep. Aktifkan toggle Bakar Motion Text lalu pilih gaya favorit pada dropdown Style Motion Text.
Langkah 2 • Edit Kampanye Berjalan
Modal Edit Naskah VO
Pada halaman kampanye /pillar-campaigns/[id], klik tombol ✏️ Edit Naskah VO di item manapun. Anda bisa mengganti style teks & transisi lalu klik Re-mux Otomatis (0 Kredit).
Langkah 3 • Global Workflow
Workflow Settings
Pada tab Pengaturan Alur Kerja di detail kampanye, Anda dapat mengubah durasi transisi (0.3s / 0.5s / 0.8s) dan posisi teks (Bawah / Tengah / Atas).
✓ Value setting berhasil disalin!
