# Arsip Skrip Scratch

Folder ini berisi skrip uji coba dan inspeksi sekali pakai (`scratch-*.mjs`, `check-*`, `inspect_*`).

> [!NOTE]
> Skrip di folder ini berstatus arsip. Jalur impor relatif di dalamnya sengaja ditulis dari folder utama proyek dan tidak diperbaiki satu per satu. Jika ingin menjalankan salah satu skrip, jalankan dari folder utama atau sesuaikan jalur impor secara manual.
