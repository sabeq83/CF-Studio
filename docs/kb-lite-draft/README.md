# KB Lite — Draf Usulan

Folder ini berisi seluruh draf KB versi ringan. **Belum dipakai oleh kode.** File asli di `kb/` tidak diubah.
Antigravity yang memindahkan file ke `kb/`, menyambungkannya ke kode, dan menguji lama vs baru di staging
(lihat `antigravity_planner_metafor_kb_instructions.md`, fase P3 dan P7).

| File | Ukuran | Menggantikan | Dipakai oleh |
|---|---|---|---|
| `REALIST_VIRAL_NARRATIVE_LITE.md` | ±4 KB | REALIST_VIRAL_NARRATIVE (49 KB) — bagian hook & adegan pembuka | Planner tahap 2 |
| `VISUAL_STYLE_GUIDE_LITE.md` | ±3 KB | VISUAL_STYLE_GUIDE (33 KB) — bagian aksi visual per gaya | Planner tahap 2 |
| `VIDEO_PROMPT_CORE_LITE.md` | ±7 KB | PROMPT_SYSTEM (140 KB) — aturan prompt video | RE campaign, Deconstruct, Bridge, pillar lama |
| `VOICE_AUDIO_LITE.md` | ±5 KB | PROMPT_SYSTEM bagian audio + REALIST Section IX (voice matrix) | Storyboard, RE, Deconstruct, Multiplier |
| `METAPHOR_PHYSICS_LIBRARY_LITE.md` | ±4 KB | PROMPT_SYSTEM III.A, XIII, M72/80/87 + REALIST Section VII | Gaya Metafora (planner & storyboard) |
| `MANDATE_GLOSSARY_LITE.md` | ±3 KB | Kebutuhan memuat PROMPT_SYSTEM hanya untuk arti label "Mandate NN" | Semua prompt yang masih menyebut nomor mandate |
| `PROMPT_SYSTEM_INVENTORY.md` | – | – | Peta setiap aturan Prompt System → modul tujuan / alasan dibuang, plus daftar konflik |

Catatan:
- `REALIST_VIRAL_NARRATIVE_LITE` dan `VISUAL_STYLE_GUIDE_LITE` adalah bahan untuk satu KB planner (`PLANNER_CREATIVE_KB`) di fase P3.
- Modul tidak pernah dimuat sekaligus; setiap proses hanya memuat yang relevan (tabel di `PROMPT_SYSTEM_INVENTORY.md` bagian D).
- Konflik terpenting: Mandate 2 Prompt System ("tanpa metafora") ikut terkirim ke planner tahap 2 dan bertentangan dengan gaya Metafora.
