# REALIST VIRAL NARRATIVE — LITE (Planner Edition)

> SUBORDINATE RULE: The selected Visual Style mandate (Metaphor / Investigation / Cinematic) in the
> prompt ALWAYS overrides this file. This file is a pattern bank, never a list to copy word-for-word.

## 1. Purpose
Help the planner write ONE scroll-stopping opening per row:
- `hook` = spoken line only (8–11 words), no camera directions.
- `visual_action` = the opening scene (clip 1) only: what the camera sees in the first 2–3 seconds.

## 2. Hook Psychology (3 checks)
Every hook must pass all three:
1. **Pattern Interrupt** — breaks the scroll (surprise, contrast, unexpected question).
2. **Clarity** — understood in one listen, one idea only.
3. **Relevance** — tied to the row's Context / W's Matrix and the target audience's daily life.

Emotional drivers to rotate: Curiosity, Concern (soft fear), Desire, Relief. Avoid insults, profanity,
aggressive shaming, and testimonial claims ("saya sembuh", "ibu saya sembuh").

## 3. Hook Archetypes (spirit only — DO NOT copy the examples)
| Archetype | Spirit | Pattern |
|---|---|---|
| The Hidden Signal | reveals an overlooked sign | "Tanda kecil ini sering diabaikan sampai…" |
| The Myth Flip | contradicts a common belief | "Banyak yang mengira X, padahal…" |
| The Living Analogy | body condition explained by a physical object | "Saat [benda] [rusak], [sistem] ikut [akibat]…" |
| The Daily Moment | a relatable routine moment | "Setiap pagi kita [kebiasaan], tanpa sadar…" |
| The Question Gap | an open question the video answers | "Kenapa [gejala] justru muncul saat [situasi]?" |

**Dynamic rule:** combine the archetype spirit with the row's audience, context, and angle to write a
NEW sentence. Each row must use a different archetype or a different object/situation.

## 4. Opening Scene Rules (`visual_action`)
- Describe ONE clear moment: subject + action + camera move + light/mood. 1–2 sentences.
- Show the PROBLEM or the PHENOMENON first. Do not show product packaging in clip 1 unless the mode is
  Product-First.
- Make it physical and visible (texture, motion, change of state) — not abstract words.
- Different rows must not reuse the same main object, location, or camera move.

## 5. Object-Metaphor Algorithm (use when Visual Style = Metaphor, or for a "Living Analogy" hook)
1. **Physics of the problem** — clogged? heavy? brittle? dirty? leaking? thickening? overheating?
2. **Household object with the same physics** — pipe, hose, strainer, sponge, twig, balloon, rubber band,
   engine, filter, glass of liquid.
3. **Sensory shock** — add crust, sludge, crack, rust, slow drip, bulge, steam.
4. **Opening frame only** — show the object in its stressed state. The fix/product belongs to later clips.

Mini bank (health → object), for inspiration only:
| Condition physics | Object idea |
|---|---|
| Narrowed / clogged flow (blood pressure, cholesterol) | clear pipe with yellow crust, red liquid slowing in a thin hose, clogged strainer |
| Thick / sticky fluid | syrup-thick liquid barely moving through a funnel |
| Pressure / tension | rubber band squeezing a fruit, balloon on a bending glass pane |
| Brittle / weak | dry twig snapping, cracked desert soil |
| Toxins / dirt | ink drop clouding clear water, black-soaked sponge |
| Low energy | battery draining to red, wilting leaf |

## 6. Short-Form Structure Reference (for context only)
Planner writes only the opening, but it should fit the SEP flow used later in the storyboard:
**Setup** (hook + problem) → **Escalation** (why it matters) → **Payoff** (solution / natural ingredient / product).

## 7. Forbidden in Planner Output
- Copying any example sentence from this file or from the prompt.
- Testimonials, cure claims, guaranteed results, doctor impersonation.
- Hard-sell CTA ("klik keranjang kuning", "promo terbatas") inside hook or visual_action.
- Human faces in Faceless styles; medical devices as the hook visual in Metaphor style.
