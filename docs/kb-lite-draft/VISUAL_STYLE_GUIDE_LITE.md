# VISUAL STYLE GUIDE — LITE (Planner Edition)

> SUBORDINATE RULE: The Visual Style chosen in the planner configuration is a HARD LOCK.
> Use only the block below that matches it. Ignore the other blocks.

## 1. How to write a `visual_action`
Formula (1–2 sentences): **[Camera move] + [Subject/object] + [Action or change of state] + [Light/mood]**
Example shape: "Slow push-in macro on a clear pipe as thick yellow crust narrows the red flow, cold side light."
- One subject, one action, one camera move.
- Visible physics beats adjectives (drip, crack, bulge, swirl, steam).
- Keep it AI-video safe: simple background, few objects, no on-screen text needed.

## 2. Style Blocks (pick the one that matches the planner's Visual Style)

### A. Metafora Objek Faceless (`metaphoric_faceless`)
- Subject: household object that mirrors the body condition (see REALIST LITE §5).
- Presence: object only in clip 1 — no faces, no hands, no medical devices, no product, no ingredients.
- Camera: macro push-in, cross-section view, overhead top-down, slow-motion detail.
- Light: clean tabletop, single soft key light or cold side light; neutral or dark seamless background.
- Physics cues: viscous flow, crust build-up, crack spreading, bulging under pressure, liquid clouding.

### B. Investigasi Fakta Faceless (`investigative_faceless`)
- Subject: documents, lab sheets, charts, evidence board, magnifier, red marker.
- Presence: objects only; no faces.
- Camera: rack focus between evidence, slow push-in, top-down desk view.
- Light: desk lamp pool of light, dim room, high contrast.

### C. Cinematic / Default (`Cinematic`)
- Subject: real situation from the row's Context (person, place, routine) — faceless crops allowed.
- Camera: slider, slow dolly in, shallow focus.
- Light: motivated natural light (window, morning, warm lamp).

### D. Product Showcase (only when Hook Mode = Product-First)
- Subject: product hero on a clean surface.
- Camera: orbit or slider; macro on texture.
- Light: soft studio light, warm accent.

## 3. Camera Vocabulary (short list)
Slow push-in · Pull-back reveal · Macro detail · Cross-section · Overhead top-down · Rack focus ·
Slider · Orbit · Slow motion · Time-lapse.
Rotate camera moves across rows — do not repeat the same move in consecutive rows.

## 4. Light & Mood (short list)
| Emotion | Light |
|---|---|
| Concern / tension | cold side light, dark background, low key |
| Curiosity / mystery | single spotlight, shadows, rack focus |
| Warmth / relief | golden soft light, warm wood surface |
| Clean / trust | bright softbox, white or pastel background |

## 5. 9:16 Composition Rules
- Main action in the center of the frame (avoid bottom and right edges where TikTok UI sits).
- Leave calm space at top or bottom for subtitles.
- Stack elements vertically (top: context, middle: subject, bottom: detail).

## 6. Forbidden in Planner `visual_action`
- Messy household clichés, crying faces, hospital beds.
- Product or packaging in clip 1 when Hook Mode = Problem/Context-First.
- Mixing styles (e.g., metaphor object + person with blood-pressure meter in the same opening).
